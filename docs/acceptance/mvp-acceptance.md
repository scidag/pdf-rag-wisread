# Wisread MVP 验收文档

## 1. 验收目标

MVP 需要验证「上传文档 → AI 理解 → 文档问答 → 来源追溯」完整闭环，并满足注册登录、文档隔离、引用可信和基础性能要求。

## 2. 验收数据集

固定使用 5 份测试 PDF，每份 1 个文档类别，共 20 个人工问题。

| 文档 | 类别 | 问题数 |
| --- | --- | --- |
| 论文.pdf | 学术论文 | 4 |
| 技术文档.pdf | 技术文档 | 4 |
| 合同.pdf | 合同 | 4 |
| 行业报告.pdf | 行业报告 | 4 |
| 学习资料.pdf | 学习资料 | 4 |

每个文档准备标准答案，并记录答案对应的页码和原文片段，用于引用准确率判定。

## 3. 20 题问题模板

### 论文

1. 本文提出的核心方法是什么？
2. 实验使用了哪些数据集？
3. 本文的主要结论是什么？
4. 作者指出了哪些局限或未来工作？

### 技术文档

1. 该功能的安装步骤是什么？
2. 关键配置项有哪些？
3. 常见错误码分别表示什么？
4. 支持哪些版本或平台？

### 合同

1. 合同的有效期限是多久？
2. 违约责任如何约定？
3. 付款条件和金额是什么？
4. 争议解决方式是什么？

### 行业报告

1. 市场规模或用户规模是多少？
2. 主要增长驱动因素是什么？
3. 主要玩家有哪些？
4. 报告指出了哪些风险？

### 学习资料

1. 本章的核心概念是什么？
2. 关键公式或定义是什么？
3. 文档中的示例说明了什么？
4. 课后练习的标准答案是什么？

## 4. 指标定义

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 答案正确率 | 人工判定答案与标准答案一致 | >= 85% |
| 引用准确率 | 引用存在，且页码、原文正确 | >= 90% |
| 幻觉回答 | 答案中出现文档不存在的关键信息 | <= 5% |
| 无答案测试 | 文档不存在信息时必须返回固定文案 | 100% |

## 5. 自动化测试矩阵

| 场景 | 验证方式 | 通过标准 |
| --- | --- | --- |
| 注册 | Playwright + API | 注册成功并进入工作区 |
| 登录 | Playwright + API | 登录成功并恢复会话 |
| 上传 | API + 状态轮询 | 20MB PDF 在 60 秒内 READY |
| 问答 | SSE 流式 | P95 < 10 秒，首字 < 5 秒 |
| 引用 | answer_sources 落库 | 每个有效 `[n]` 都有来源 |
| 删除文档 | API | 级联删除 chunks/messages/answer_sources/MinIO 文件 |
| 用户隔离 | API | 用户 A 访问用户 B 文档/会话返回 404 |
| 移动端 | Playwright 390px | 无横向溢出，核心流程可用 |
